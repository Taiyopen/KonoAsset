讓「就用這個素材吧！」變得更簡單的 VRChat 素材管理工具

全力協助你整理容易變得雜亂的素材

## 安裝

開啟 [Releases](https://github.com/siloneco/KonoAsset/releases/latest)，點擊 `KonoAsset_X.X.X_x64-setup.exe` 下載安裝程式並執行  
X.X.X 為版本號碼

> [!WARNING]
> 由於沒有進行付費的軟體簽章，啟動安裝程式時可能會出現警告  
> 若要繼續，請點擊「其他資訊」，再點擊「仍要執行」

## 功能
- [x] 新增並管理素材等內容
- [x] 以文字搜尋已新增的素材
- [x] 從 BOOTH 取得商品資訊
- [x] 分別管理虛擬角色本體、虛擬角色相關素材與世界素材
- [x] 可為素材設定分類、標籤、備註、前置素材等資訊
- [x] 拖放檔案即可新增
- [x] 自動解壓縮 ZIP 檔案
